# Project Instructions

Tech stack:

- Python
- FastAPI
- Jinja2 templates
- SQLite
- Plain HTML/CSS/JS

When making changes:

- Prefer minimal modifications.
- Reuse existing patterns and architecture.
- Do not introduce new frameworks or dependencies unless explicitly requested.
- Do not refactor unrelated code.
- Preserve backward compatibility where possible.

Do not read or analyze:

- samples/
- specs/
- uploads/
- .idea/
- .git/
- venv/
- specs/
- __pycache__/
- .pytest_cache/
- df.db
- *.sqlite
- *.db
- *.log
- git-cmd.exe


These paths contain datasets, generated files, caches, binaries, or development artifacts and are not relevant to application logic.
